## Presentazione

::: {#sezione_418991.xhtml#asset_testo}
Fisica capovolta è un libro di testo innovativo perché:

-   è stato scritto cercando di gestire il carico cognitivo per chi
    apprende;
-   è stato scritto per essere letto su un supporto elettronico di
    qualunque tipo, non è una trasposizione digitale di un vecchio
    libro;
-   è un progetto aperto alla collaborazione di docenti e studenti;
-   può essere importato su piattaforma Moodle e personalizzato da
    qualunque classe/docente.

Il libro è strutturato in due volumi a loro volta suddivisi in moduli.
La struttura di ogni modulo prevede diverse sezioni evidenziate da un
colore di sfondo e da riquadri:

-   [un interrogativo problematico tratto dal mondo reale **Per
    iniziare**;]{style="background-color: #ffcc99;"}
-   alcune brevi frasi con **Il modello di riferimento** che riassume la
    teoria;
-   [**Esempi** di applicazione del modello, alcuni dei quali realizzati
    attraverso brevi video;]{style="background-color: #cccccc;"}
-   [una parte finale **Per riasumere** in cui l\'interrogativo iniziale
    è ripreso alla luce del modello e degli esempi
    presentati;]{style="background-color: #ffcc99;"}
-   [una sezione di **F.A.Q.** con curiosità, approfondimenti,
    chiarimenti;]{style="background-color: #ffffcc;"}
-   per ogni grandezza fisica introdotta sono presentate tabelle con gli
    ordini di grandezza e schede su strumenti e tecniche di misura;
-   [**Esercizi**]{style="background-color: #e6e6ff;"}
-   **Schede di laboratorio** pensate per attività da svolgere in
    un\'ora di lezione.

Il primo volume è indicato per il primo anno del biennio degli istituti
professionali, ma può facilmente essere esteso a qualunque altro
indirizzo.

## 1.1. La misura e le grandezze fisiche

::: {#sezione_298127.xhtml#asset_testo}
+-----------------------------------------------------------------------+
| *[**PER INIZIARE**]{style="text-decoration: underline;"}*             |
|                                                                       |
| *Come fai a misurare qualcosa? Prova a misurare un oggetto vicino a   |
| te e prova a scrivere nel dettaglio i passaggi che hai fatto*         |
|                                                                       |
| ::: centro_70                                                         |
| *[![](./img/simpsons_tv_room_by_ilyich.jpg)]{.Apple-style-span}*      |
| :::                                                                   |
+-----------------------------------------------------------------------+

Quando eseguiamo una misura ci occupiamo sempre di un fare un confronto
e se possibile anche un conteggio.

+-----------------------------------------------------------------------+
| *[**IL MODELLO DI                                                     |
| RIFERIMENTO**]{style="text-decoration: underline;"}*                  |
|                                                                       |
| *[Definizione]{style="text-decoration: underline;"}*                  |
|                                                                       |
| Misurare significa assegnare un numero a *qualcosa*                   |
|                                                                       |
| *[Osservazioni]{style="text-decoration: underline;"}*                 |
|                                                                       |
| -   Anche la posizione in un elenco, un numero di maglia o di         |
|     telefono assegnano un numero a qualcosa/qualcuno, ma non sono una |
|     misura                                                            |
|                                                                       |
| -   Per fare una misura ci serve un riferimento (o un campione)       |
|                                                                       |
| *[Definizione]{style="text-decoration: underline;"}*                  |
|                                                                       |
| La misura è il rapporto tra il *qualcosa* e il riferimento.           |
|                                                                       |
| *[Definizione]{style="text-decoration: underline;"}*                  |
|                                                                       |
| L\'unità di misura è il campione o riferimento che si sceglie per     |
| fare una misura.                                                      |
|                                                                       |
| *[Osservazione]{style="text-decoration: underline;"}*                 |
|                                                                       |
| -   Il riferimento deve essere il più possibile uguale per tutti      |
|                                                                       |
| -   Indicheremo la generica unità di misura con il simbolo U          |
+-----------------------------------------------------------------------+

+-----------------------------------------------------------------------+
| *[Esempio]{style="text-decoration: underline;"}*                      |
|                                                                       |
| Nella vita quotidiana usiamo spesso la nostra persona come            |
| riferimento per fare confronti: \"Lei è più piccola di me\", \"Io     |
| sono più brava di lui\".                                              |
+-----------------------------------------------------------------------+

La fisica si occupa di cose misurabili, perché attraverso l\'uso dei
numeri può usare il linguaggio e gli strumenti della matematica, e in
questo modo riesce a spiegare qualcosa che è accaduto o a fare
previsioni su qualcosa che accadrà.

+-----------------------------------------------------------------------+
| *[**IL MODELLO DI                                                     |
| RIFERIMENTO**]{style="text-decoration: underline;"}*                  |
|                                                                       |
| *[Definizione]{style="text-decoration: underline;"}*                  |
|                                                                       |
| Una grandezza fisica è *qualcosa* che si può misurare                 |
|                                                                       |
| *[Definizione]{style="text-decoration: underline;"}*                  |
|                                                                       |
| Grandezze dello stesso tipo si dicono omogenee.                       |
|                                                                       |
| *[Osservazioni]{style="text-decoration: underline;"}*                 |
|                                                                       |
| -   Tra grandezze omogenee si possono fare tutte le 4 operazioni      |
|     dell\'aritmetica.                                                 |
|                                                                       |
| -   Tra grandezze non omogenee si possono fare solo moltiplicazioni e |
|     divisioni.                                                        |
+-----------------------------------------------------------------------+

+-----------------------------------------------------------------------+
| *[Esempio]{style="text-decoration: underline;"}*                      |
|                                                                       |
| La simpatia non si può misurare.                                      |
|                                                                       |
| *[Esempio]{style="text-decoration: underline;"}*                      |
|                                                                       |
| Non posso confrontare i goal di un calciatore con i canestri di un    |
| giocatore di basket o i punti di un tennista.                         |
+-----------------------------------------------------------------------+

La misura esprime il rapporto tra una qualunque grandezza e un\'altra
dello stesso tipo assunta come unità di misura: la misura di una
grandezza fisica sarà sempre espressa come un numero insieme a una unità
di misura.

+-----------------------------------------------------------------------+
| **[[[[PER                                                             |
| RIASSUME                                                              |
| RE]{style="font-size: small;"}]{style="font-family: Arial, sans-serif |
| ;"}]{style="color: #000000;"}]{style="text-decoration: underline;"}** |
|                                                                       |
| La richiesta iniziale era ambigua. In ogni caso quando misuriamo      |
| *qualcosa* eseguiamo i seguenti passaggi:                             |
|                                                                       |
| -   prendiamo *qualcosa* e ne scegliamo una caratteristica;           |
| -   scegliamo un riferimento per questa caratteristica;               |
| -   definiamo un modo per fare un confronto con il riferimento;       |
| -   contiamo quante volte è necessario replicare il riferimento per   |
|     avere quello che ci interessa.                                    |
+-----------------------------------------------------------------------+
:::

## 1.2. Gli strumenti di misura

::: {#sezione_298128.xhtml#asset_testo}
+-----------------------------------------------------------------------+
| **PER INIZIARE**                                                      |
|                                                                       |
| *Tutti i giorni in diverse occasioni usiamo alcuni strumenti di       |
| misura. Prova a elencare le caratteristiche comuni di alcuni di       |
| questi strumenti*                                                     |
|                                                                       |
|   ---------------------- -------------------------------------------- |
|   ![](./img/watch.jpg)   ![](./img/geratherm-rapide-termometer.jpg)   |
|   ---------------------- -------------------------------------------- |
+-----------------------------------------------------------------------+

La nostra persona è molto usata come riferimento quando eseguiamo una
misura, ma usare in alternativa uno strumento consente di misurare un
maggior numero di grandezze e aiuta a individuare uno standard.

+-----------------------------------------------------------------------+
| *[**IL MODELLO DI                                                     |
| RIFERIMENTO**]{style="text-decoration: underline;"}*                  |
|                                                                       |
| *[*[Definizione]{style="                                              |
| text-decoration: underline;"}*]{style="text-decoration: underline;"}* |
|                                                                       |
| Uno strumento di misura è un oggetto con una scala graduata o un      |
| display che permette di eseguire una misura.                          |
|                                                                       |
| *[Definizione]{style="text-decoration: underline;"}*                  |
|                                                                       |
| La risoluzione di uno strumento rappresenta la più piccola variazione |
| che lo strumento riesce a misurare.                                   |
|                                                                       |
| *[Definizione]{style="text-decoration: underline;"}*                  |
|                                                                       |
| La portata di uno strumento rappresenta il più grande valore che lo   |
| strumento riesce a misurare.                                          |
|                                                                       |
| *[Osservazioni]{style="text-decoration: underline;"}*                 |
|                                                                       |
| -   La portata ottimale è all\'incirca il doppio del valore della     |
|     misura.                                                           |
|                                                                       |
| -   La risoluzione rappresenta un sottomultiplo del valore della      |
|     misura che si può leggere sullo strumento.                        |
+-----------------------------------------------------------------------+

+-----------------------------------------------------------------------+
| *[Esempio]{style="text-decoration: underline;"}*                      |
|                                                                       |
| Per fare la misura di una grandezza G che vale 160 U serve, ad        |
| esempio, uno strumento di portata 300 U (altri valori potrebbero      |
| essere 200 U, 400 U, etc) e di risoluzione 4 U (altri valori valori   |
| potrebbero essere 1 U, 2 U, 8 U, 10 U, 20 U, etc). Il risultato della |
| misura si indica G=160 U.                                             |
+-----------------------------------------------------------------------+

Per misurare una grandezza non è sufficiente specificare uno strumento,
ma bisogna specificare un procedimento indicando la precisa sequenza
delle operazioni necessarie per compiere la misura.

+-----------------------------------------------------------------------+
| *[**IL MODELLO DI                                                     |

| *[Esempio]{style="text-decoration: underline;"}*                      |
|                                                                       |
| Uno smartphone fornisce all\'utente tanti numeri corrispondenti a     |

Tutte le grandezze che si misurano con lo stesso procedimento sono dello
stesso tipo. Tutti i procedimenti che producono gli stessi risultati
sono tra di loro equivalenti (si possono usare diversi strumenti per una
stessa grandezza).

+-----------------------------------------------------------------------+
| **[PER RIASSUMERE]{style="text-decoration: underline;"}**             |
|                                                                       |
| *Uno strumento di misura:*                                            |
|                                                                       |
| -   *è un oggetto, un qualcosa che si può prendere in mano,           |
|     spostare;*                                                        |
|                                                                       |
| -   *fornisce un numero associato alla caratteristica di un oggetto,  |
|     un materiale, un fenomeno;*                                       |
|                                                                       |
| -   *usa una unità di misura comune a tanti altri strumenti dello     |
|     stesso tipo.*                                                     |
+-----------------------------------------------------------------------+

+-----------------------------------------------------------------------+
| **[F. A. Q.]{style="text-decoration: underline;"}**                   |
|                                                                       |
| *La risoluzione rappresenta la precisione con cui viene eseguita una  |
| misura?*                                                              |
|                                                                       |
| La precisione di una misura indica quanto questa è vicina al valore   |
| vero della grandezza. Se una certa quantità vale, ad esempio,         |
| esattamente 27 U, uno strumento con risoluzione 3 U che misuri        |
| proprio 27 U è più preciso di uno con risoluzione 0,01 U che misuri   |
| 21,89 U, anche se quest'ultimo ha una risoluzione minore del primo.   |
|                                                                       |
| *Come faccio a trovare i sottomultipli di una misura espressa con un  |
| numero decimale?*                                                     |
|                                                                       |
| Togli la virgola e cerca i sottomultipli del numero ottenuto; scegli  |
| uno di questi sottomultipli e rimetti la virgola nella stessa         |
| posizione che aveva nel numero di partenza. Ad esempio: G=1,44 U.     |
| Cerchi i sottomultipli di 144 e scegli, ad esempio, 4; il risultato è |
| 0,04 U. Altro esempio: G=0,018 U. Cerchi i sottomultipli di 18 e      |
| scegli, ad esempio, 6; il risultato è 0,006 U.                        |
+-----------------------------------------------------------------------+

## 1.3. Il Sistema Internazionale

::: {#sezione_298129.xhtml#asset_testo}
+-----------------------------------------------------------------------+
| **PER INIZIARE**                                                      |
|                                                                       |
| Prendi il volantino di un supermercato alimentare o di elettromestici |
| e individua tutte le unità di misura presenti.                        |
|                                                                       |
| <div>                                                                 |
|                                                                       |
| ![](./img/TagCloudUmisura.PNG)                                        |
|                                                                       |

In molte occasioni usiamo diverse unità di misura per una stessa
grandezza. Questo accade per ragioni storiche (una volta si faceva così)
o culturali (ogni paese ha le sue abitudini), ma quando bisogna
comunicare i risultati di una misura possono sorgere problemi: quando si
viaggia, quando si compra da un altro paese, quando ci sono progetti che
coinvolgono persone provenienti da culture e nazioni diverse.

+-----------------------------------------------------------------------+
| *[**IL MODELLO DI                                                     |
| RIFERIMENTO**]{style="text-decoration: underline;"}*                  |
|                                                                       |
| *[*[Definizione]{style="                                              |
| text-decoration: underline;"}*]{style="text-decoration: underline;"}* |
|                                                                       |
| Il Sistema Internazionale (S. I.) delle unità di misura è un accordo  |
| sulla scelta delle unità di misura da usare per ogni grandezza        |
| fisica.                                                               |
|                                                                       |
| *[Definizione]{style="text-decoration: underline;"}*                  |
|                                                                       |
| Una grandezza fisica è fondamentale quando non ne se serve un\'altra  |
| per definirla. Una grandezza fisica è derivata quando è definita      |
| dalla combinazione di una o più altre grandezze.                      |
|                                                                       |
| *[Osservazione]{style="text-decoration: underline;"}*                 |
|                                                                       |
| -   Il Sistema Internazionale definisce uno standard.                 |
|                                                                       |
| -   Le grandezze fondamentali del S. I. sono 7, ma in questo corso ne |
|     vedremo solo 5.                                                   |
+-----------------------------------------------------------------------+

Le grandezze fondamentali sono come i colori primari (giallo, rosso,
blu), dai quali si possono ottenere tutte le altre grandezze, proprio
come dai colori primari si possono ottenere tutti gli altri colori. Come
per i colori è solo un accordo che stabilisce quali siano le
fondamentali (i colori primari): nei prodotti digitali si usano i colori
RGB (red, green, blue) come base per ottenere tutti gli altri, dove il
giallo è sostituito con il verde.

una grandezza per noi molto naturale, perché già da quando siamo piccoli

interessa.

| *A volte si usano parole diverse per indicare la lunghezza, come, ad  |
| esempio, larghezza, profondità, altezza, spessore, ma visto che tutte |
| si possono misurare con lo stesso strumento e usando la stesso unità  |
| di misura sono tutte lunghezze. Il diverso nome porta una             |
| informazione aggiuntiva su come la misura deve essere eseguita        |
| (questo diventerà più chiaro quando parleremo di vetori nel Modulo    |
| 3). Quando invece usiamo la parola volume per parlare del livello     |
| audio, di un libro o di una unità di archiviazione dati, usiamo la    |
| parola con un significato diverso.*                                   |
+-----------------------------------------------------------------------+

+-----------------------------------------------------------------------+
| **[F. A. Q.]{style="text-decoration: underline;"}**                   |
|                                                                       |
| *Qual è la differenza tra volume e capacità?*                         |
|                                                                       |
| La capacità rappresenta il volume che è possibile contenere in un     |
| dato recipiente. Solitamente si usa per i liquidi o i gas, ma anche   |
| per indicare lo spazio disponibile degli zaini o dei bagagliai delle  |
| auto.                                                                 |
|                                                                       |
| *Che cos'è un metro?*                                                 |
|                                                                       |
| Il metro era stato inizialmente definito teoricamente dividendo in    |
| dieci milioni di parti un quarto della lunghezza del meridiano        |
| terrestre. Questa prima definizione risale al 1791 e, a seguito di    |
| una misura accurata del meridiano terrestre, nel 1799 è stato         |
| costruito un esemplare campione in platino. Questo prototipo è        |
| diventato un riferimento internazionale nel 1889, ma nel 1960 è       |
| iniziata la ricerca per una definizione che garantisse maggiore       |
| stabilità. Oggi il metro è definito attraverso la velocità della luce |
| (vedi sezioni 5.1 e 8.3).                                             |

## 1.5. Massa e densità

::: {#sezione_298132.xhtml#asset_testo}
+-----------------------------------------------------------------------+
| [**PER INIZIARE**]{style="text-decoration: underline;"}               |
|                                                                       |
| *Elenca tre parole che ti vengono in mente quando nella vita          |
| quotidiana senti la parola massa, e tre parole che ti vengono in      |
| mente quando senti la parola densità.*                                |
|                                                                       |
| ::: centro_70                                                         |
| ![](./img/crowd-of-people.jpg)                                        |
| :::                                                                   |
+-----------------------------------------------------------------------+

La massa è una delle grandezze fisiche più difficili da spiegare. Agli
inizi della storia della Fisica la massa è stata associata alla
difficoltà di spostare un oggetto fermo o di frenare uno in movimento,
ma negli ultimi cento anni diverse teorie ed esperimenti hanno cambiato
la sua definizione. Nel linguaggio quotidiano la parola è spesso legata
alla quantità di \"qualcosa\".

+-----------------------------------------------------------------------+
| [**IL MODELLO DI RIFERIMENTO**]{style="text-decoration: underline;"}  |
|                                                                       |
| *[*[Definizione                                                       |
| (operativa)]{style="                                                  |
| text-decoration: underline;"}*]{style="text-decoration: underline;"}* |
|                                                                       |
| La massa gravitazionale si misura con la bilancia a bracci uguali e   |
| la sua unità di misura è il kilogrammo, che si indica con il simbolo  |
| kg.                                                                   |
|                                                                       |
| *[Definizione]{style="text-decoration: underline;"}*                  |
|                                                                       |
| La massa inerziale rappresenta la capacità di un \"qualcosa\" a       |
| opporsi ai cambiamenti di movimento.                                  |
|                                                                       |
| *[Osservazioni]{style="text-decoration: underline;"}*                 |
|                                                                       |
| -   Tutti gli esperimenti realizzati fino a oggi indicano che massa   |
|     gravitazionale e massa inerziale sono numericamente uguali, per   |
|     questo usiamo semplicemente la parola \"massa\".                  |
|                                                                       |
| -   La massa è una grandezza fondamentale e il suo simbolo è m.       |
|                                                                       |
| -   Nei seguenti casi il simbolo m assume un diverso significato:     |
|                                                                       |
| -   l = 6,25 m (metri)                                                |
|                                                                       |
| -   V = 6,25 mL (milli)                                               |
|                                                                       |
| -   m = 6,25 kg (massa)                                               |

**La bilancia a bracci uguali**

::: centro_70
![](./img/400px-Unbalanced_scales.svg.png)

Procedura di misura:

1.  si pone su un piatto l\'oggetto di cui vogliamo conoscere la massa
    (m)
2.  si dispongono sull\'altro piatto delle masse campione fino a quando
    la bilancia non è in equilibrio
3.  il valore della massa m è dato dalla somma delle masse campione
    poste sull\'altro piatto della bilancia
4.  se le masse campione non hanno una risoluzione sufficiente, si avrà
    m~1~\<m\<m~2~, dove m~1~ e m~2~ sono due masse campione; per cui
    m=(m~1~+m~2~)/2
5.  può accadere che la bilancia abbia una sensibilità superiore a
    quella della sua risoluzione (si sbilancia con un capello, ma la più
    piccola massa di riferimento vale solo 1 mg)

## 1.6. Tempo, valore medio e incertezza

::: {#sezione_298134.xhtml#asset_testo}
+-----------------------------------------------------------------------+

Il tempo è quella grandezza che permette di mettere in ordine le cose
che accadono intorno a noi, perché ci consente di distinguere tra il
prima e il dopo. Il significato del tempo che useremo nel corso di
fisica è lo stesso, che usiamo nella vita di ogni giorno dalla
suddivisione delle nostre giornate alle gare sportive, dalle storie del
passato alla musica.

+-----------------------------------------------------------------------+
| [**IL MODELLO DI RIFERIMENTO**]{style="text-decoration: underline;"}  |
|                                                                       |
| *[Definizione (operativa)]{style="text-decoration: underline;"}*      |
|                                                                       |
| Il tempo si misura con cronometro e la sua unità di misura è il       |
| secondo, che si indica con il simbolo s.                              |
|                                                                       |
| *[Osservazione]{style="text-decoration: underline;"}*                 |
|                                                                       |
| -   Il tempo è una grandezza fondamentale e il suo simbolo è t.       |
|                                                                       |
| -   Il tempo si misura anche in secoli, anni (a/y), mesi (m),         |
|     settimane, giorni (g/d), ore (h), minuti (m).                     |
|                                                                       |
| -   In alcuni casi i minuti vengono indicati con ' e i secondi con "; |
|     in altri si usano come formati gg/mm/aaaa, mm/dd/yyyy, hh:mm:ss   |
|                                                                       |
| -   Valgono le seguenti equivalenze                                   |
|                                                                       |
| -   1 giorno = 24 ore                                                 |
|                                                                       |
| -   1 ora = 60 minuti                                                 |
|                                                                       |
| -   1 minuto = 60 secondi                                             |
|                                                                       |
| -   1 ora = 3600 secondi                                              |

In alcune occasioni le misure ripetute di una stessa grandezza possono
produrre risultati diversi. Questo è quello che accade quando cerchiamo
di misurare l\'apprendimento: ogni volta che facciamo una verifica di
fisica capita che la valutazione sia diversa, e quando vogliamo
riassumere in un unico voto le valutazioni di tutte le verifiche ne
facciamo la media. Misurare l\'apprendimento è molto complesso e di
questo non si occupa la fisica, ma anche quando misuriamo il periodo di
un pendolo o il tempo di reazione di una persona troviamo misure diverse
per la stessa grandezza fisica e anche in queste situazioni calcoliamo
la media delle misure.

Quando troviamo misure diverse per una stessa grandezza fisica significa
che non tutte le condizioni sperimentali sono sotto controllo (il
risultato di accendere e spegnere il cronometro dipende, ad esempio,
dalla risoluzione dello strumento e dalla persona) e che il fenomeno che
stiamo osservando è di tipo probabilistico (come, ad esempio, il lancio
di una moneta o di due dadi). Per queste ragioni diciamo che la misura
di una grandezza fisica è associata a una incertezza.

+-----------------------------------------------------------------------+
| [**IL MODELLO DI RIFERIMENTO**]{style="text-decoration: underline;"}  |
|                                                                       |
| [*Definizione*]{style="text-decoration: underline;"}                  |
|                                                                       |
| L'incertezza di una misura indica quanto sono vicini i diversi valori |
| di quello che vogliamo misurare.                                      |
|                                                                       |
| *[Osservazione]{style="text-decoration: underline;"}*                 |
|                                                                       |

| (decalogo ISO):                                                       |
|                                                                       |
| 1.  incompleta definizione di quello che vogliamo misurare            |
| 2.  imperfetta realizzazione di quello che vogliamo misurare          |
| 3.  scelta di un campione non rappresentativo                         |
| 4.  imperfetta conoscenza delle condizioni ambientali di influenza e  |
|     inadeguata conoscenza degli effetti di tali condizioni            |
| 5.  errore di lettura di uno strumento                                |
| 6.  risoluzione finita dello strumento                                |
| 7.  valori inesatti dei campioni e dei materiali di riferimento       |
| 8.  valore inesatto di costanti e altri parametri che intervengono    |
|     nell'analisi dati                                                 |
| 9.  approssimazioni e assunzioni che intervengono nel metodo e nella  |
|     procedura di misura                                               |
| 10. variazioni in osservazioni ripetute di quello che vogliamo        |
|     misurare sotto condizioni di misura apparentemente identiche.     |

| **[F. A. Q.]{style="text-decoration: underline;"}**                   |
|                                                                       |
| *Quando è iniziato il tempo?*                                         |
|                                                                       |
| L\'origine del tempo può essere associata a quella del nostro         |
| Universo, che ha all\'incirca 13-14 miliardi di anni. Per ragioni     |
| pratiche sono stati introdotti alcuni riferimenti utili alla          |
| datazione storica o scientifica. Un primo riferimento è stato il 1°   |
| gennaio 4713 a. C. che definisce il giorno giuliano (Julian Date in   |
| inglese); altri riferimenti sono stati il 17 novembre 1859 (Modified  |
| Julian Date, usato per le missioni spaziali negli anni \'60), il 24   |
| maggio 1968 (Truncated Julian Date, definito dalla NASA), o il 1°     |
| gennaio 1900 (Dublin Julian Date, usato nei computer).                |
|                                                                       |
| *Che cos\'è un secondo?*                                              |
|                                                                       |
| Per scegliere un riferimento per l\'unità di misura del tempo è       |
| necessario trovare un fenomeno che ripeta in modo sempre uguale nel   |
| tempo. La prima proposta fu quella di scegliere un giorno, ovvero una |
| rotazione completa della Terra intorno al suo asse, e per ragioni di  |
| comodità su suddiviso in parti più piccole, 86400; la scelta di       |
| questo numero è legata al fatto che ha tantissimi sottomultipli.      |

Una richiesta come \"spostati di un metro\" o \"tira la palla\" in molti
casi può essere ambigua, perché non sono specificate tutte le
informazioni per far capire cosa bisogna fare.

+-----------------------------------------------------------------------+
| [**IL MODELLO DI RIFERIMENTO**]{style="text-decoration: underline;"}  |
|                                                                       |
| *[Definizione]{style="text-decoration: underline;"}*                  |
|                                                                       |
| Un vettore è un \"qualcosa\" caratterizzato da un modulo, una         |
| direzione, un verso e un punto di applicazione; si rappresenta con    |
| una freccia.                                                          |
|                                                                       |
| *[Osservazione]{style="text-decoration: underline;"}*                 |
|                                                                       |
| -   Come nel caso della freccia, si individuano una punta e una coda. |
|                                                                       |
| [Definizione]{style="text-decoration: underline;"}                    |
|                                                                       |
| Una grandezza è scalare, quando per specificarla serve un numero; una |
| grandezza è vettoriale, quando per specificarla serve un vettore.     |
|                                                                       |
| [Osservazione]{style="text-decoration: underline;"}                   |
|                                                                       |
| -   Sono grandezze scalari il volume, la massa, la densità e il       |
|     tempo; la lunghezza è una grandezza vettoriale.                   |
+-----------------------------------------------------------------------+

Le operazioni matematiche più semplici come la addizione non sempre sono
così banali, soprattutto quando vengono eseguite non con grandezze
scalari, ma con quelle vettoriali. Quando usiamo grandezze vettoriali
bisogna usare una matematica particolare e in questo caso 1+1 può dare
un risultato qualunque tra 0 e 2. Nell\'attesa di imparare questa
matematica, possiamo usare alcune scorciatoie grafiche, che nei casi più
semplici ci permettono di ottenere lo stesso il risultato corretto.

+-----------------------------------------------------------------------+
| [**IL MODELLO DI RIFERIMENTO**]{style="text-decoration: underline;"}  |
|                                                                       |
| [Osservazione]{style="text-decoration: underline;"}                   |
|                                                                       |
| -   Le grandezze vettoriali non si sommano con la somma algebrica, ma |
|     con il metodo punta-coda.                                         |
|                                                                       |
| -   La somma di due grandezze vettoriali si fa con il righello, non   |
|     con la calcolatrice                                               |
|                                                                       |
| *[Metodo punta-coda]{style="text-decoration: underline;"}*            |
|                                                                       |
| Per fare la somma di due vettori:                                     |
|                                                                       |
| -   trasla la coda di un vettore sulla punta di un altro;             |
|                                                                       |
| -   unisci la coda del primo vettore con la punta del secondo;        |
|                                                                       |
| -   misura quanto è lunga la nuova freccia e aggiungi l\'unità di     |
|     misura (eventualmente facendo una proporzione).                   |

Tutte le volte che nella vita quotidiana usiamo la parola forza, la
associamo al mettere in movimento o frenare \"qualcosa\". Spesso si usa
la parola forza associata alla deformazione di \"qualcosa\", ma anche in
questo caso abbiamo un movimento dei contorni del \"qualcosa\": ad
esempio, quando schiacciamo una bottiglia di plastica o allunghiamo un
elastico.

|                                                                       |

|     \"qualcos\'altro\".                                               |
|                                                                       |
| -   Esistono in natura quattro forze fondamentali: la forza           |
|     gravitazionale, la forza elettromagnetica, la forza nucleare      |
|     forte e la forza nucleare debole; in questo corso studiamo solo   |
|     le prime due perché più semplici.                                 |

Quando il modello di punto materiale non è più sufficiente per fornire
la descrizione di un fenomeno, si può utilizzare una prima correzione a

solo capire se è fermo rispetto al contesto in cui è inserito, ma serve
anche stabilire se può ruotare su se stesso. Nel caso di un oggetto con

## 2.4. Pressione ed equilibrio dei fluidi

::: {#sezione_300065.xhtml#asset_testo}
+-----------------------------------------------------------------------+
| **PER INIZIARE**                                                      |
|                                                                       |
| Pensa a cosa succede se cerchi di fare un buco nell\'acqua            |

Fino a questo punto ci siamo sempre occupati di ridurre tante forze che
agiscono su un corpo a una sola forza. Ci sono situazioni in cui è
invece interessante sapere come la forza viene distribuita sulla
superficie su cui è esercitata: è il caso, ad esempio, degli oggetti che
servono per fare buchi o tagliare, oppure di quelli che permettono di
camminare su superfici particolari come la neve o un pavimento di
cemento fresco.

+-----------------------------------------------------------------------+
| [**IL MODELLO DI RIFERIMENTO**]{style="text-decoration: underline;"}  |
|                                                                       |
| *[Definizione (operativa)]{style="text-decoration: underline;"}*      |
|                                                                       |
| La pressione si misura con il manometro e la sua unità di misura è il |
| pascal, che ha come simbolo Pa.                                       |
|                                                                       |
| *[Osservazione]{style="text-decoration: underline;"}*                 |
|                                                                       |
| -   La pressione è una grandezza derivata e il suo simbolo è p.       |
|                                                                       |
| -   La pressione è una grandezza scalare.                             |
+-----------------------------------------------------------------------+

+-----------------------------------------------------------------------+
| *[Esempio]{style="text-decoration: underline;"}*                      |
|                                                                       |
| Diagramma della misura della pressione dell\'aria (101 325)           |
|                                                                       |

|                                                                       |
| ![](./img/MD_pressione_aria.png)                                      |
|                                                                       |

+-----------------------------------------------------------------------+
| [**IL MODELLO DI RIFERIMENTO**]{style="text-decoration: underline;"}  |
|                                                                       |
| *[Osservazione]{style="text-decoration: underline;"}*                 |
|                                                                       |
| -   Nella pratica vengono usate anche altre unità di misura:          |
|                                                                       |
|     -1 atm = 101325 Pa                                                |
|                                                                       |
|     -1 bar = 100 000 Pa                                               |
|                                                                       |
|     -1 atm = 760 mmHg                                                 |
|                                                                       |
| *[Definizione (formale)]{style="text-decoration: underline;"}*        |
|                                                                       |
| dove F è la forza e A l\'area della superficie sulla quale viene      |
| applicata la forza.                                                   |
|                                                                       |
| *[Osservazione]{style="text-decoration: underline;"}*                 |
|                                                                       |
| -   Nella definizione precedente quello che davvero conta è la        |
|     componente della forza perpendicolare alla superficie.            |
+-----------------------------------------------------------------------+

Quando abbiamo un liquido o un gas non possiamo utilizzare il modello di
corpo rigido e lo studio delle condizioni di equilibrio sulla base delle
forze, sebbene in principio possibile, diventa molto complicato a causa
di un numero molto elevato di fattori da considerare. La pressione
permette di semplificare l\'analisi di questo tipo di situazioni.

+-----------------------------------------------------------------------+
| [**IL MODELLO DI RIFERIMENTO**]{style="text-decoration: underline;"}  |
|                                                                       |
| *[Definizione]{style="text-decoration: underline;"}*                  |
|                                                                       |
| Un fluido è un liquido o un gas.                                      |
|                                                                       |
| *[Principio di Pascal]{style="text-decoration: underline;"}*          |
|                                                                       |
| La pressione esercitata in un punto qualsiasi di un fluido si         |
| trasmette in ogni altro punto del fluido con la stessa intensità.     |
|                                                                       |
| *[Legge di Stevin]{style="text-decoration: underline;"}*              |
|                                                                       |
| dove p0 è la pressione rispetto a un riferimento, h l\'altezza di un  |
| fluido rispetto a quel riferimento, d la densità del fluido, g il     |
| campo gravitazionale.                                                 |
|                                                                       |
| *[Definizione]{style="text-decoration: underline;"}*                  |
|                                                                       |
| Un fluido è in equilibrio quando la pressione rimane costante in ogni |
| suo punto.                                                            |
+-----------------------------------------------------------------------+

Quando immergiamo, ad esempio, una palla nell\'acqua è come se facessimo
un buco: l\'acqua si oppone alla nostra azione in modo analogo a come lo
fa un muro con un chiodo. Il galleggiamento dei corpi nei fluidi è il
risultato delle forze che il fluido esercita sulla parte di corpo
immerso. L\'insieme di tali forze è molto complesso, ma è possibile
descrivere il loro effetto attraverso una sola forza, uguale alla loro
somma.

+-----------------------------------------------------------------------+
| [**IL MODELLO DI RIFERIMENTO**]{style="text-decoration: underline;"}  |
|                                                                       |
| *[Principio di Archimede]{style="text-decoration: underline;"}*       |
|                                                                       |
| dove F~A~ è la forza (o spinta) di Archimede, d la densità del        |
| fluido, V il volume della parte di oggetto immersa nel fluido, g il   |
| campo gravitazionale.                                                 |
+-----------------------------------------------------------------------+

| esercitare una certa pressione, il bicchiere inizia a immergersi      |

| diminisce.                                                            |
